# Network

## Owns

- Peer-to-peer connectivity and Kademlia/DHT behavior.
- Peer and provider discovery, advertisements, and provider state.
- Content requests, file and chunk transfer, and cache announcements.
- Demand metadata, demand-driven caching, and basic latency-based provider selection.

## Does not own

- Availability agreements, epochs, challenges, or availability verification.
- Payment accounting, settlement, escrow, or collateral.
- Availability or payment smart contracts.

The network team owns this domain's internal structure.
